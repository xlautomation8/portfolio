## Repository Overview

This repository contains a responsive personal portfolio website built with static HTML, CSS, and JavaScript.

### Project structure

- `index.html` — main portfolio landing page
- `style.css` — site styling and visual design
- `script.js` — interactions and behavior
- `certificates.html` — certifications showcase page
- `assets/` — profile image, PDF resume, and certificate assets
- `tests/` — Playwright-based automated tests

## Run Locally

You can open the site directly in a browser or run a small local HTTP server:

```bash
python -m http.server 8000
```

Then open:

```text
http://localhost:8000
```
